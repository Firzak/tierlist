# Tier List 

A simple and lightweight web app for creating tier lists from a CSV file.

## Features

* Import a list of items from a CSV file
* Automatically find game covers when available
* Drag and drop items into S, A, B, C and D tiers
* Automatically save your current tier list locally in your browser
* Add new items manually
* Remove items from the list
* Retry missing cover searches
* Replace missing covers manually with an image or URL
* Works with games, movies, books, or any other type of content

## CSV Format

Your CSV file only needs one column:

```csv
title
Clair Obscur: Expedition 33
Split Fiction
PEAK
```

For the best results, use the **exact official title** of each item, including capitalization, spaces, punctuation and special characters.

For game lists, it is recommended to have an AI check your titles before importing them to improve cover matching.

## Usage

1. Open the website.
2. Click **Import Tier List**.
3. Select your CSV file.
4. Wait for the covers to be loaded.
5. Drag and drop the items into the tiers.
6. Your progress is automatically saved in your browser.

To start a new tier list, simply import another CSV. The new list will replace the current one.

## Privacy

Your tier list is stored locally in your browser. No account is required.
